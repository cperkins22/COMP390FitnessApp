# FitnessApp
A JavaFX application for tracking workouts and meals.

## Features
- Login interface with Username and PIN
- Create and save workout plans
- Track workouts in live time from your created templates
- Track meals on a daily basis by logging calories and macronutrients
- Track personal stats (height, weight, weight goal)
- Clean UI built with FXML and CSS
- Database structure to save user data

## How to Run
- open the maven tool window (if running from intellij)
- navigate to Plugins -> Javafx -> javafx:run
- run from the javafx:run plugin from the Maven window in IntelliJ
